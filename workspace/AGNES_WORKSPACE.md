# What `agnes init` installed in this workspace

This directory is the **analyst-side counterpart** of Keboola's Agnes deployment. `agnes init` (or `agnes init --force`) populates it from the operator-managed template repo (this one). The template overrides Agnes's bundled default skeleton.

## Files Agnes manages

| Path | Purpose | Hand-edit? |
|---|---|---|
| `CLAUDE.md` | Project instructions for Claude Code (rules, metrics workflow, query patterns) | Read-only — regenerated by `agnes init --force` |
| `.claude/settings.json` | Hooks for `agnes pull` / `agnes push` / `agnes self-upgrade` + `statusLine` + permissions | Read-only — regenerated by `agnes init --force` |
| `.claude/commands/agnes-private.md` | `/agnes-private` slash command — mark session as private | Read-only |
| `.claude/commands/update-agnes-plugins.md` | `/update-agnes-plugins` slash command | Read-only |

## Files YOU own

| Path | Purpose |
|---|---|
| `.claude/CLAUDE.local.md` | Your personal notes — preserved across `agnes init --force`, uploaded to server on `agnes push` |
| `*.parquet` (under `server/parquet/`) | Pulled by `agnes pull` — do not edit, do not commit |
| `*.duckdb` (under `user/duckdb/`) | Local views over parquets — do not edit |

## Common commands

| | Command |
|---|---|
| What data do I have? | `agnes catalog` |
| Schema of one table | `agnes schema <table>` |
| Five sample rows | `agnes describe <table> -n 5` |
| Query local data | `agnes query "SELECT ..."` |
| Query remote (BigQuery) | `agnes query --remote "..."` |
| Estimate remote scan cost | `agnes snapshot create <name> ... --estimate` |
| Fetch remote subset | `agnes snapshot create <name> --as <local>` |
| Manual pull | `agnes pull` |
| Manual push | `agnes push` |
| Current cache size | `agnes disk-info` |

## Re-initialize

```
agnes init --force
```

Diffs the current template against your workspace, prompts before overwriting, preserves `.claude/CLAUDE.local.md`.

## Uninstall

Just delete the workspace directory. Server-side data is unaffected.
